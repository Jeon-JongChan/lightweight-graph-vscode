- 추가 수정: 2026-10-29 23:36 KST 사용자 요청에 따라 `.tools/.test/` 디렉터리 전체를 삭제했다. 내부의 임시 결과뿐 아니라 로컬 테스트 스크립트, 비교 fixture, VSIX 추출본도 함께 삭제했다. 다시 생성되는 로컬 자료가 커밋 후보에 잡히지 않도록 `.tools/.test/` 전체를 ignore한다.
